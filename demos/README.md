# Symphony storefront concepts

Ten distinct interactive visual proposals are hosted with GitHub Pages under `/demos/`. The `atelier` page preserves the original concept. The root `index.html` is the gallery.

## Features
Responsive layouts; image gallery filters; photo-detail modal; accessible labels; in-session inspiration saves; search; navigation; source photography reused from `assets/facebook-full`.

## Shopify implementation
These static previews are not Shopify themes and do not process orders. Use a client-approved direction to implement theme sections in Liquid and connect product, collection, inventory, and checkout data within the client's Shopify store. Do not invent catalog details or publish client assets without permission.
